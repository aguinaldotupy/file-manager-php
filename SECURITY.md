# Security Policy

## Supported Versions

Only the latest major version receives security updates and bug fixes:

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| 3.x     | :x:                |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within `tupy/filemanager`, please do **NOT** disclose it in a public GitHub issue.

Instead, please send an email directly to the maintainer:

📧 **Aguinaldo Tupy** - [aguinaldo.tupy@gmail.com](mailto:aguinaldo.tupy@gmail.com)

Please include:
- A detailed description of the vulnerability and potential attack vectors.
- Clear steps to reproduce or a Proof of Concept (PoC).
- Suggested mitigation or fix, if available.

We will acknowledge receipt of your report within 48 hours and coordinate a fix and release promptly.
